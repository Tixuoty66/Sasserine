# Sasserine

Bienvenue dans cette première version d'**atlas interactif** de Sasserine. L'idée est de proposer une navigation en trois niveaux :

1. **carte générale** de la cité ;
2. **carte détaillée** d'un quartier ;
3. **fiches de lieux** puis **fiches de PNJ** reliées entre elles.

Tous les quartiers ne sont pas encore finalisés et les lieux seront progressivement complétés. Concernant les fiches PNJ, je ne suis pas encore au clair sur ce que cela permettra de voir.
